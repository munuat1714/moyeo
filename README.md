# 모두의 여행 MVP

친구들이 각자 취향을 입력하면 그룹 공통 취향을 분석해 부산에서 경주로 떠나는 1박 2일 코스 3개를 추천하고, 투표로 최종 일정을 확정하는 모바일 우선 프로토타입입니다.

## 실행 방법

필요 환경:

- Node.js 20 이상
- npm 10 이상

```bash
npm install
npm run dev
```

터미널에 표시된 로컬 주소를 브라우저에서 열고 모바일 화면 너비로 확인합니다.

## 검증 명령

```bash
npm test
npm run build
npm run preview
```

## 구현 기능

- 부산 출발, 경주 목적지의 1박 2일 여행방 생성
- 날짜, 인원, 이동수단 설정
- 친구 4명의 참여 및 취향 입력 상태 확인
- 참여자별 여행 유형, 속도, 음식, 분위기, 필수 제약 입력
- 참여자 전원 입력 전 코스 생성 잠금
- 선택 인원 기반 그룹 공통 취향 분석
- 그룹 취향이 반영된 추천 코스 3개
- 코스별 공통 60%, 차별 40% 일정 표시
- 추천 이유, 예상 가격, 이동시간, 취향 일치율 비교
- 참여자별 비공개 투표
- 동률 시 공동 1위 후보 간 결선투표
- 투표 결과에 따른 최종 일정 확정
- 날짜별 시간표와 지도형 이동 동선
- 교통, 숙소, 체험 예약 연결 및 완료 상태 시뮬레이션
- `localStorage` 기반 시연 상태 유지와 초기화

## 빠른 시연

1. 홈에서 `새 여행 만들기`를 누릅니다.
2. 미리 입력된 부산 → 경주 조건으로 여행방을 만듭니다.
3. 여행방에서 `데모 응답 한 번에 채우기`를 누릅니다.
4. 그룹 취향 분석과 추천 코스 3개를 확인합니다.
5. `친구들과 투표하기`를 누른 뒤 `데모 투표 한 번에 채우기`를 사용합니다.
6. 1위 코스를 확정합니다.
7. 최종 여행에서 일정, 동선, 예약 탭을 확인합니다.
8. 예약 항목의 `예약 연결`을 눌러 완료 상태를 확인합니다.

우측 상단의 초기화 버튼을 누르면 처음부터 다시 시연할 수 있습니다.

## 대표 데이터

- 여행: 부산 → 경주
- 기간: 2026년 8월 15일~16일
- 인원: 민지, 서준, 유나, 현우
- 공통 취향: 맛집, 감성 카페, 사진
- 소수 취향: 역사, 액티비티
- 필수 제약: 견과류 알레르기

실제 지도·교통·숙박·식당 API와 결제는 연결하지 않습니다. 모든 장소, 가격, 예약 상태는 사용자 흐름 검증을 위한 시드 데이터와 시뮬레이션입니다.
